# Private RC1 Beta Program

**Goal:** 20–50 real users before public release.

---

## Program Structure

### Duration
4 weeks: Week 1 (onboarding) → Week 2-3 (active usage) → Week 4 (feedback)

### Participant Tiers

| Tier | Count | Profile | Requirements |
|------|-------|---------|-------------|
| Developer | 15-25 | Active GitHub contributors | TypeScript/React experience, daily coding |
| AI Power User | 10-15 | Daily AI tool users | Cursor, Copilot, or Claude Code experience |
| Open Source Maintainer | 5-10 | 1k+ star repos | Experience with large codebases |
| **Total** | **30-50** | | |

### Recruitment Channels
- GitHub Discussions (repository)
- Twitter/X (developer community)
- Discord/community channels
- Direct outreach to maintainers

---

## Participant Tasks

| Week | Task | Deliverable |
|------|------|-------------|
| 1 | Install and configure | First-run survey |
| 1 | Open a project, generate AGENTIC.md | Completion check |
| 2 | Fix 3 bugs in a sample repo | Bug fix task |
| 2 | Refactor a module | Refactor task |
| 3 | Add a feature to a project | Feature task |
| 3 | Review AI-generated code changes | Review task |
| 4 | Freeform usage + feedback | Exit survey |

---

## Metrics Collected

| Metric | Collection Method | Target |
|--------|------------------|--------|
| Completion Rate | Automated task tracking | 90%+ |
| Time To Complete | Automated timing | Per-task baseline |
| Error Rate | Error log analysis | <5% |
| Abandonment Rate | Session tracking | <10% |
| Confusion Events | Session recording | <3 per session |
| Trust Rating | Per-task survey | 8+/10 |
| Satisfaction Rating | Exit survey | 8+/10 |

---

## Feedback Rounds

### Round 1 (End of Week 1)
Focus: Installation, first-run experience, initial impressions

### Round 2 (End of Week 3)
Focus: Core workflows, trust, error recovery

### Summary (End of Week 4)
Focus: Overall satisfaction, feature requests, drop-off analysis

---

## Data Collection

1. In-app telemetry (opt-in)
2. Session recordings (opt-in)
3. Weekly surveys (required)
4. Exit survey (required)
5. GitHub Issues (optional)

---

## Exit Criteria for Public Release

| Criterion | Target | Measurement |
|-----------|--------|-------------|
| Participants | 20+ | Enrollment count |
| Completion Rate | 90%+ | Task tracking |
| Trust Rating | 8+/10 | Survey |
| Satisfaction | 8+/10 | Survey |
| Critical Bugs Found | 0 | Bug tracker |
| P0 Regressions | 0 | Automated tests |
